# Point2Prompt

**Point at your UI. Paste a perfect prompt.**

Point2Prompt is a tiny bookmarklet for AI-assisted frontend work. It lets you
select real elements on any webpage, attach change intent, and copy a structured
prompt for Claude Code, Codex, Cursor, or a GitHub issue.

AI coding agents are good at changing files. Humans are good at seeing what
feels wrong. Point2Prompt connects those two worlds.

## Why this exists

Describing UI changes to an AI agent is still weirdly clumsy.

You take a screenshot. Draw an arrow. Type something like "the small text below
the second card on the right." Then the agent has to guess which component,
selector, style, or copy block you meant.

Point2Prompt turns the thing you can see into the context your coding agent can
use:

- DOM selector
- element text
- bounding box
- computed visual styles
- React component hints when available
- per-element instructions
- agent-specific output format

## Install

1. Create a GitHub repo, for example `point2prompt`.
2. Push these files to the `main` branch.
3. Enable GitHub Pages with GitHub Actions as the source.
4. Open the deployed install page.
5. Drag the **Point2Prompt** button to your bookmarks bar.
6. Open any webpage and click the bookmark.

The bookmarklet injects `assets/editor.css` and `assets/editor.js` into the
current page. Everything runs client-side.

## Usage

For recording a polished product demo, open [`demo.html`](demo.html). It is a
fake vibe-coded website designed specifically for testing selection, multi-select,
and prompt copying.

| Action | Result |
| --- | --- |
| Click | Select one element |
| Shift-click | Add an element to the selection |
| Drag | Select elements inside a region |
| Up / Down | Move to parent / first visible child |
| Left / Right | Move to previous / next sibling |
| Cmd/Ctrl + C | Copy the generated prompt |
| Esc | Clear the current selection |

## Output formats

Point2Prompt can shape the copied brief for:

- Claude Code
- Codex
- Cursor
- GitHub Issue
- Markdown

## Intent presets

Instead of writing every instruction from scratch, pick a preset first:

- Rewrite copy
- Adjust spacing
- Improve visual hierarchy
- Fix responsive layout
- Improve contrast
- Match nearby style
- Polish interaction state
- Custom instruction

## Example prompt

```text
UI change brief generated by Point2Prompt

Task: Update the selected UI elements using the element context below.

Page: http://localhost:3000/dashboard
Viewport: 1440x900
Output target: Codex

Selected elements:

1. h1.hero-title
   selector: body > main:nth-of-type(1) > section.hero:nth-of-type(1) > h1.hero-title:nth-of-type(1)
   rect: x=112, y=164, w=620, h=96
   text: "Welcome back to your workspace"
   intent: Improve visual hierarchy
   instruction: Make this headline sharper and less generic.
   react: App > DashboardPage > Hero
   styles: font=..., size=64px, color=rgb(...), background=rgba(...), display=block
   html: <h1 class="hero-title">Welcome back to your workspace</h1>

Please make the smallest code change that satisfies the instructions.
Preserve nearby behavior and visual intent unless the instruction says otherwise.
```

## Product thesis

This is not another AI coding tool.

It is a pointing layer.

The browser already knows the exact element, text, size, position, style, and
sometimes the source component. Point2Prompt packages that context into a clean
change brief so the agent can spend less time guessing and more time editing.

## Development

This project is intentionally static.

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

Edit:

- `index.html` for the install page
- `assets/editor.js` for bookmarklet behavior
- `assets/editor.css` for injected UI styling

Before publishing, update the GitHub link in `index.html` if your repository is
not `LobsterQBA/point2prompt`.

## Privacy

Point2Prompt does not send page content anywhere. The generated prompt is copied
to your clipboard from inside the browser.
